# Delatte-Guidry et al. - Juvenile Oyster Cycling CADO (Coastal Acidification and low Dissolved Oxygen)
 
Data and reproducible code for a cycled multistressor experiment on juvenile eastern oysters. This study characterized the plastic responses of juvenile oysters to diel cycling of simultaneous coastal stressors (pH and DO), and  how those responses might change with prior exposure to stressors. 

> Status: Manuscript in preparation. This repository is under active development and will be finalized upon publication.
